📦 INSTALARE RAPIDĂ - 3 PAȘI:

1. VERIFICĂ PYTHON:
   - Deschide CMD (Command Prompt)
   - Tastează: python --version
   - Trebuie să vezi: Python 3.10.x sau mai nou
   - Dacă NU: Instalează de la https://www.python.org/downloads/
     IMPORTANT: Bifează "Add Python to PATH" la instalare!

2. RULEAZĂ SCRIPTUL DE INSTALARE:
   - Click dreapta pe fișierul:
     INSTALL_WINDOWS.ps1
   - Alege: "Run with PowerShell"
   - Urmează instrucțiunile

3. GATA!
   - Dublu-click pe shortcut-ul de pe Desktop
   SAU
   - Dublu-click pe:
     C:\Claude\dpia-generator\RUN_DPIA_GENERATOR.bat
